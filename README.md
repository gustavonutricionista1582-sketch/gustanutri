LANDING PAGE PREMIUM - GUSTAVO SOUZA | NUTRICIONISTA ESPORTIVO

Objetivo

Desenvolver uma landing page premium de alta conversão para captação de pacientes via WhatsApp.

O foco do projeto é transmitir autoridade, confiança, profissionalismo e incentivar o visitante a agendar uma consulta.

A página deve parecer desenvolvida por uma agência especializada em profissionais da saúde e medicina esportiva.

NÃO quero um template genérico.

Quero um design exclusivo, moderno, minimalista e extremamente refinado.

Referência

Tenho como referência estratégica a landing page do nutricionista Rafael Kenji.

Utilize apenas a estrutura de conversão e a organização das informações como inspiração.

Não copie o design.

Crie uma identidade própria.

O resultado deve ser visualmente superior, mais moderno e mais elegante.

Identidade Visual

A identidade visual deve ser baseada na logomarca enviada.

Utilize a logomarca exatamente como foi fornecida, sem alterações.

A identidade transmite força, performance e resultados.
